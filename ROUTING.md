## DeltaRoute (Δ): automatic model delegation

DeltaRoute is the multi-provider aggregator. Apply this policy in every chat; the user-scoped prompt hook reapplies a compact reminder each turn. Claude keeps planning, final review, creative control and integration. Classify each prompt; tiny self-contained questions stay in Claude. Delegation has real startup/context overhead, so do not launch workers merely to create activity. An explicit request for independent feedback takes precedence.

Roles: Codex for bounded coding, debugging, tests and independent feedback; Gemini through supported Antigravity CLI for quick iteration and large-context work; Cursor for integration; Perplexity through gstack for cited research; Grok through Cursor for analysis of public source packets collected with gstack/Perplexity; native repetitive-worker (Haiku) for repetitive read-only tasks. Codex may use up to two native subagents with inherited permissions. This broker caps external concurrency at two. Native live X access is unverified; require original URLs/dates and label missing evidence. Models/allowances depend on each account.

Before the first external delegation, inspect list_workers once and reuse that catalogue until failure or configuration changes. Use recommend_route when uncertain. submit_task needs an absolute cwd, bounded assignment, necessary context and acceptance criteria. Workers do not inherit this chat. Default read-only; code mode requires a clean Git checkout and creates an isolated worktree from HEAD. Uncommitted source changes are not copied. For dirty trees, obtain read-only advice and implement in Claude.

If no independent work remains, use submit_task wait_seconds=30 or 45 to collect short jobs in one call; otherwise submit asynchronously. Collect remaining get_task results with wait_seconds=45, not tight polling. Compact responses omit repeated prompts/raw packets; detail=full is for troubleshooting. When answerTruncated is true or more evidence is needed, inspect the full status artifact with context-mode ctx_index(path) / ctx_search. Review committed/uncommitted diffs and run appropriate checks before integration. Do not merge blindly, overwrite user changes or remove needed worktrees.

Specialist skill library: DeltaRoute has pinned animation, Three.js, Blender, context-efficiency and verification skills, plus an optional Remotion collection subject to its upstream licensing status. recommend_route accepts task text and exposes up to three relevant paths; workers receive a small task-specific brief. Read the relevant full skill only when needed. The DeltaRoute entry skill is installed in ~/.claude/skills/deltaroute. Renderer skills do not install Blender or guarantee photorealism.

For TikTok/Instagram URLs, use category video_analysis to extract real frames and attach them to the Codex vision worker. State sampled coverage and missing speech; no paid video/audio API is used. social_research collects original URLs and enriches up to four posts with available native dates/metrics. Never claim platform-wide trend rank or growth from an undated or single-snapshot sample. Do not post or sign up for paid scraping services.

Token/skill routing: when the optional context-mode tools are installed, use local ctx_execute/ctx_execute_file for bulky logs/data and ctx_index(path) then batched ctx_search for repeated lookup. Otherwise use ordinary local parsing and bounded summaries. Read files normally when editing. Keep raw data in artifacts and return focused findings. ALL web browsing stays on gstack /browse; do not use built-in WebSearch/WebFetch or context-mode URL fetching. Only index browser output already saved locally.

For token/cache/cost audits, use native CLI input/output/cache counters and list_workers(include_usage=true). Read relevant installed context-optimization or context-compression guidance returned by recommend_route. Provider caching is automatic and provider-specific: keep stable prefixes and tool configuration within a session. Cached reads are a subset of input; model list-price equivalents are not subscription invoices. For actual quota/context pressure, save a bounded workflow handoff and preserve work; never auto-clear a chat or invent recovery. Use skills-manifest.json for a read-only inventory. External token-optimization, rescue-tokens or skills-smart-manager skills are optional existing-user additions, not required bundled dependencies. Simulated context percentages/unloading never establish savings. Load full skill bodies only when needed.

Research source packets validate requested primary publishers, including structured URLs. Missing required sources get one targeted Perplexity repair, then one independent gstack primary-page search if needed; no Grok call runs with missing required sources. Inspect sourceValidation for attempts and requirements. Never retry indefinitely.

Provider recovery is automatic by default inside submit_task (fallback=true): try a finite task-appropriate chain of installed subscription workers on auth expiry, quota, outage, timeout or model unavailability. Do not resubmit the same failed job yourself. Cursor and Grok share one account for cooldowns. Each code attempt starts from the original pinned HEAD in a fresh worktree; preserve unsuccessful attempts. list_workers shows retryAfter; a later task probes again after cooldown. fallback=false is an explicit single-provider probe.

If handoff.action is wait_for_worker_shutdown or terminationConfirmed=false, stop editing that task workspace until its previous process is confirmed stopped. Otherwise, if get_task returns needs_coordinator, immediately continue the original assignment in THIS Claude conversation using its task/attempt artifacts and available tools, respecting existing permissions. Preserve partial work and disclose unavailable capabilities; do not recursively invoke Claude CLI or repeatedly resubmit exhausted workers. If current evidence or required network access is unavailable too, state the specific blocker with the saved task path instead of claiming completion. On non-provider task/safety/input errors, fix the actual cause in scope; do not use a fallback to evade restrictions. Never claim an unavailable worker ran. No paid API fallback, new credits, credential access, session export outside authorized local browser tooling or limit bypass. Provider-side overages remain outside broker control. Existing approvals and deny rules remain in force; delegation does not authorize publishing, deployments or messages to others. External workers must not recursively call this broker or spawn other AI CLIs. MODEL_ROUTER_WORKER=1 suppresses the routing hook; Codex may still use its own bounded native subagents.
For heavy coding, multi-step animation and long video workflows, load DeltaRoute references/heavy-workflows.md. Preserve the original prompt in a saved workflow contract; use submit_task create_workflow/run_step/checkpoint and get_task(workflow_id). Keep dependencies gated by coordinator review and evidence, enforce file scope, use pinned coding/review worktrees and retrieve only relevant context. Do not turn routine checkpoints into user permission requests.
Use recommend_route review evidence to refine model/task fit after capability checks; defaults are task specialties, not proven quality rankings. Record worker checkpoint reviews so model/version-specific strengths persist. Managed head replacement is performed only by the external DeltaRoute supervisor after the prior head stops; both heads limited means pause and wait for verified recovery, with no recursive coordinator spawning. Native app chats keep their host.
